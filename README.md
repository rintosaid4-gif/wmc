# Weda Bay Medical Center (WMC) — Website Profil

Website profil statis untuk GitHub Pages. Dibangun dengan HTML, CSS, dan JavaScript tanpa backend atau database.

## Fitur
- Desain responsif untuk desktop, tablet, dan ponsel.
- Navigasi mobile.
- Profil ringkas WMC berdasarkan publikasi yang dapat diakses publik.
- Bagian program kesehatan, kolaborasi, publikasi, dan kontak.
- Tautan sumber berita.
- SEO dasar, aksesibilitas dasar, dan prefers-reduced-motion.
- Tidak mengumpulkan atau menyimpan data pribadi pengunjung.

## Menjalankan secara lokal
Buka `index.html` di browser, atau jalankan server statis lokal, misalnya:
```bash
python -m http.server 8000
```
Lalu buka `http://localhost:8000`.

## Publikasi ke GitHub Pages
1. Buat repository baru, misalnya `wmc-profile`.
2. Unggah seluruh isi folder proyek ini ke root repository (pastikan `index.html` berada di root).
3. Buka **Settings → Pages**.
4. Pada **Build and deployment**, pilih **Deploy from a branch**.
5. Pilih branch `main` dan folder `/ (root)`, lalu klik **Save**.
6. Tunggu proses deployment. GitHub akan menampilkan URL Pages repository.

## Hal yang perlu dikonfirmasi oleh pengelola WMC sebelum tayang resmi
- Logo resmi dan panduan identitas visual.
- Alamat operasional yang boleh dipublikasikan.
- Nomor telepon, email, website, dan akun media sosial resmi.
- Jam operasional dan informasi akses layanan.
- Visi, misi, sejarah rinci, struktur organisasi, serta nama/jabatan terbaru.
- Daftar layanan/fasilitas dan informasi dokter yang memang disetujui untuk publikasi.
- Foto kegiatan/fasilitas yang mendapat izin publikasi.

**Catatan:** halaman ini adalah profil informasi, bukan portal pendaftaran, konsultasi medis, rekam medis, atau layanan gawat darurat. Jangan menambahkan klaim layanan, jadwal, kontak, maupun data tenaga medis tanpa verifikasi resmi.
